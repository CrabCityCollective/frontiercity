# Bradrock-lettertype

Zet hier een gelicenseerd `Bradrock.woff2` (en eventueel `Bradrock.woff`) bestand
neer om het echte [Bradrock-font](https://www.1001fonts.com/bradrock-font.html)
te activeren voor alle titels/knoppen in de game.

De `@font-face`-regel in `src/app/globals.css` verwijst al naar deze map — zodra
het bestand hier staat, wordt het automatisch gebruikt in plaats van de
tijdelijke Sancreek-vervanger (zie de toelichting bovenaan `globals.css`).
